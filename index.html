Run Johnny Castaway on a Raspberry Pi

Easily turn a Raspberry Pi into a dedicated Johnny Castaway art piece by flashing an image onto an SD card.

Sure, why not?

stranded

Have you ever wondered what it would be like to run Johnny Castaway on a TV or monitor in your house all day, every day? Install this image on a Raspberry Pi and impress your aging friends or kids and later puzzle over why your electric bill seems higher at the end of the month.

Features:

  • Widescreen support (16:9 or larger)
  • Web Configuration
  • JSON API
  • Quiet hours where the display shows nothing

Setting one up

You'll need a Raspberry Pi Zero 2 W, 3, 4 or 5, a microSD card, a power supply, and a screen that accepts HDMI.

In my defense, both microSD cards and Raspberry Pis were a lot cheaper when I started this project. This 8-inch 4:3 monitor with metal housing is still about the same price, though.

Flash an SD card

The image is Raspberry Pi OS Lite (64-bit) with stranded preinstalled. Build it with Docker, on a Mac with Apple Silicon or any machine that has it:

git clone https://github.com/bertrandom/stranded-pi
cd stranded-pi
./image/build-docker.sh

Then, in Raspberry Pi Imager, open App Options and set Content Repository to the repo.json in image/out. Choose your Pi, Stranded as the operating system and your SD card, set the hostname, Wi-Fi and a password, and write the card. On first boot the Pi applies your settings and starts Johnny, and his web page is at http://<hostname>/.

Or use a Pi you already have

On a Pi running Raspberry Pi OS Lite (64-bit) Trixie, copy over the setup script and run it:

scp setup.sh <your Pi>:
ssh <your Pi> sudo ./setup.sh

It installs the latest stranded release, fetches the game's data files, writes the default settings and starts Johnny. Run it again any time to update; it keeps your settings.

The rest, including the API, is in the stranded-pi README.

About

Johnny Castaway was made by Dynamix and published by Sierra in 1992. What plays here is stranded, built on Jérémie Guillaume's open source engine Johnny Reborn. It was ported to TypeScript as stranded-web, which draws every frame on a canvas from the original game's data.

Thanks to Hans Milling for Johnny Castaway Open Source, to Alexandre Fontoura for castaway, and to everyone who worked out how the original works. Johnny Castaway belongs to its rights holders. This is a fan project, with no ties to them.

With the picture selected: Space pauses, Return steps a frame while paused, N skips to the next scene, M runs at max speed and F goes full screen.
