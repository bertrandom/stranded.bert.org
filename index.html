Run Johnny Castaway on a Raspberry Pi

Easily turn a Raspberry Pi into a dedicated Johnny Castaway art piece by flashing an image onto an SD card.

Sure, why not?

Introduction

Have you ever wondered what it would be like to run Johnny Castaway on a TV or monitor in your house all day, every day? Wonder no more - install this image on a Raspberry Pi and impress your aging friends or kids and later puzzle over why your electric bill seems higher at the end of the month.

Features:

  • Widescreen support (16:9 or larger)
  • Web configuration
  • JSON API
  • Night mode where the display shows nothing

Setup

You'll need a Raspberry Pi Zero 2 W, 3, 4 or 5, a microSD card, a power supply, and a screen that accepts HDMI.

In my defense, both Raspberry Pis and microSD cards were a lot cheaper when I started this project. This 8-inch 4:3 monitor with metal housing is still about the same price, though.

Flash an SD card

  1. Download and install the Raspberry Pi Imager, open it, and click App Options.

  2. Next to Content Repository, click Edit.

  3. Choose Use custom URL.

  4. Enter https://stranded.bert.org/repo.json and click Apply & Restart.

  5. Once Imager restarts, its title bar says it's using data from stranded.bert.org. Choose your Raspberry Pi and click Next.

  6. Choose Stranded as the operating system and click Next.

  7. Choose your SD card, then fill in the customisation settings: hostname, localisation, a user and password, and Wi-Fi. I would recommend adding your SSH public key.

  8. Write the card.

On first boot the Pi applies your settings and starts stranded. The web configuration is at http://<hostname>/.

Usage

Once it's running, Johnny should go through a variety of different scenes by himself. Controls are on the web page at http://<hostname>/:

  • A live preview of the screen, and which scene is playing
  • Pause, step a frame, skip to the next scene, or run at max speed
  • Change the day of the story, the brightness, and turn the sound on or off
  • Night mode, which pauses Johnny and turns the display off between the hours you pick, and puts a TV in standby too if it supports HDMI-CEC
  • Check for updates and install the latest release of stranded
  • Restart stranded, or reboot or shut down the Pi

With a keyboard plugged into the Pi, Space pauses, Return steps a frame while paused, N skips to the next scene and M toggles max speed. Esc quits, but stranded starts again a few seconds later.

Everything on the web page is also available as a JSON API:

curl http://<hostname>/api/status
curl -X POST http://<hostname>/api/toggle-pause

http://<hostname>/api lists every endpoint and setting, and stranded's README describes them.

About

stranded is built on Jérémie Guillaume's open source engine Johnny Reborn. Johnny Reborn already ran on the Raspberry Pi, but stranded adds some quality of life improvements and streamlines setup. The development of stranded was heavily AI assisted.

stranded-web is a port of a port - it is a Typescript implementation of stranded for embedding into web sites, like this one.

Johnny Castaway is owned by whoever owns Sierra/Dynamix now. This is an unaffiliated fan project.
